# Datasets

## Phantom Datasets (included in download)

Download from [Google Drive](https://drive.google.com/drive/folders/1LPwezlAUmxWnUo791RM3OPAhGQHq5r0v?usp=sharing) and extract into this `data/` directory.

> **Important**: Extract directly into `data/`. Do NOT create nested `data/data/...` paths.

After extraction:

```
data/
├── phantom_1/                          # Commercial phantom (Clarius API collected)
│   ├── images/                         # raw grayscale ultrasound images
│   ├── masks/                          # annotated binary masks
│   ├── images_aug/                     # (generated by dataPrepare.py)
│   │   ├── train/
│   │   ├── val/
│   │   └── test/
│   ├── masks_aug/                      # (generated by dataPrepare.py)
│   │   ├── train/
│   │   ├── val/
│   │   └── test/
│   └── meta_phantom_1_1.csv           # image metadata (micropixel, depth, etc.)
│
├── phantom_2/                          # Custom 3D phantom (A325 capture card)
│   ├── images/
│   ├── masks/
│   ├── images_aug/
│   ├── masks_aug/
│   └── meta_phantom_2_1.csv
│
└── README.md
```

### Data Preparation

After downloading, run from the **project root**:

```bash
# Prepare phantom_1 (augment + split into train/val/test NPZ)
python training/dataPrepare.py --dataset phantom_1

# Prepare phantom_2
python training/dataPrepare.py --dataset phantom_2
```

This generates augmented NPZ files used by `train.py` and `test.py`.

## dataset1: Common Carotid Artery Ultrasound Images

**Not included in this repository.** If you want to use it, please download it from [Mendeley Data](https://data.mendeley.com/datasets/d4xt63mgjm/1) and follow the license terms (CC BY 4.0).

After downloading, create the folder `data/dataset1/` and extract so the paths are:

```
data/dataset1/
└── Common Carotid Artery Ultrasound Images/
    ├── US images/              # 1100 original ultrasound images (PNG, 709x749x3)
    └── Expert mask images/     # 1100 expert-annotated masks (PNG, matching filenames)
```

Then prepare:

```bash
python training/dataPrepare.py --dataset dataset1 --no-png
```

### Specs

- 1100 ultrasound images + 1100 expert masks, resolution 709x749x3
- Mindray UMT-500Plus with L13-3s linear probe, 11 subjects
- License: CC BY 4.0

## dataset2: Carotid and Femoral Vessel Ultrasound Dataset

**Not included in this repository.** If you want to use it, please download it from [Kaggle](https://www.kaggle.com/datasets/fa8b3e1386722702d9c80a7d2d10d5d50eef20d14a604078b38d01c66fd9f356) and follow the license terms (CC BY-NC 4.0).

The path structure for dataset2 is up to you — add a config entry in `training/dataPrepare.py` `DATASET_CONFIGS` as needed.

### Specs

- 2203 train + 911 validation images from 105 videos, 11 volunteers
- Angell Pionner H20 Ultrasound Scanner
- License: CC BY-NC 4.0
