# 通过 SSH 在本机浏览器标注

`label_web.py` 复用原标注工具的图片、PNG mask 与 metadata CSV，适用于没有桌面、不能安装系统软件的服务器。只使用 Python 标准库 HTTP 服务及项目已有的 Pillow / NumPy；不需要 Qt、X11、sudo、Flask、Node 或 CDN，也不会启动训练。

## 启动

**服务器终端：**

```bash
conda activate ml_env
cd ~/Project/ultrasound/vein_segmentation
python data/collection/label_web.py PMC9883282 1 --port 8765
```

服务只绑定 `127.0.0.1:8765`。保持该终端运行，按 Ctrl+C 停止。启动输出类似：

```text
Open locally: http://127.0.0.1:8765/#token=本次启动生成的令牌
```

**本地电脑另开终端，建立 SSH 隧道：**

```bash
ssh -N -L 8765:127.0.0.1:8765 uceeqz4@berlin
```

`berlin` 换成你平时连接学校服务器的 SSH 主机名或别名；跳板机配置可继续使用原 SSH alias。这条命令留在前台、没有输出是正常的。然后在**本地浏览器**打开服务器打印的完整链接，包括 `#token=...`。令牌只保存在当前浏览器会话，重启服务后需要打开新链接。不需要开放服务器公网端口。

如果本地 8765 已被占用，可用 `ssh -N -L 8766:127.0.0.1:8765 uceeqz4@berlin`，浏览器链接相应改为 `http://127.0.0.1:8766/#token=...`。VS Code Remote SSH 也可在 Ports 面板转发远端 8765，使用显示的本地地址并附上令牌。

## 操作

- 默认显示「有效帧（复查）」。左侧还可选择「待标注 / 已确认 / 已跳过 / 已排除（可恢复） / 全部」，逐张切换、复查已有标签。
- `1` 蓝色静脉（255），`2` 红色动脉（128），`E` 橡皮擦（0）；左键拖动绘制，笔径以原图像素为单位。修改显示颜色不会改动已有 mask 的类别值。
- 鼠标放在画布内，滚轮向上增大笔刷、向下缩小，每步 2 像素，范围 2–100 像素。动脉、静脉和橡皮擦分别记住大小；Shift＋滚轮仍可横向查看图像，Ctrl/Command＋滚轮保留浏览器行为。
- `Ctrl+Z` 撤销最近 20 次画笔操作或清空；`Tab` 查看原图。可调叠加透明度，支持适应窗口和 100%–300% 缩放。
- 核对两类后点「确认动静脉并保存」或 `Ctrl+S`。保存成功才将 `mask_status` 设为 `true`。train/val/test 字段保持原样，不因保存按钮变化。
- **PMC 保存时自动清理 mask**：在原图像素尺度上做半径 2 的闭运算、填封闭孔洞，动静脉分别保留最大 8 连通区域，去掉其余孤立区域。最低面积为 1 像素，不做开运算，不因面积小删除唯一的受压细线；空类别仍为空，不自动把静脉改成动脉。保存后显示变化像素数，可返回上一张查看。此规则对应当前每类最多一个目标的标注约定，不能用于保留同类多个目标的任务。仅在点击保存时执行，不批量改写现有标注，加载/跳过/排除时不执行。
- 「跳过此帧」将状态改成 `pass`，不会把当前草稿保存成训练标签。可以在「已跳过」中找回并重新标注。
- 空 mask 保存有确认提示。完全塌缩且确实无静脉不等于整张图都应为空；仍需核对动脉。
- 对没有有效超声内容的帧，选择无效原因，点「删除此帧（排除训练）」。这会标记无效并移到下一帧，**不会删除原图或已有 mask**。「撤销刚才的排除」可撤销最近一次操作；以后也可在「已排除」中恢复。恢复后进入待确认，核对并保存才重新作为分割真值。
- 已排除帧只读，不能误点保存又加入训练。「跳过」只表示暂时不做标签，不等于图像无效；只有「排除训练」会让该帧同时退出时序输入。
- 未保存修改在切换/离开页面时会提醒；刷新或关闭浏览器不会自动保存草稿。保存失败时先看页面错误，不要关闭页面。

图像和 mask 始终保留原像素尺寸。浏览器画布只负责显示和编辑整数标签，后台写入单通道 PNG（0/128/255），不会把彩色透明叠加图当 mask。已保存的 mask 优先于预标注；验证/测试帧不会载入模型建议。

数据写到原来的 `data/datasets/PMC9883282/masks/` 和 `meta_PMC9883282_1.csv`，继续使用现有数据管线和部分标签混合损失。其他按相同 metadata CSV 采集的数据集也可用此入口，仿体默认画笔为未分型血管（255）。

PMC 的 `full3` 队列只有静脉、动脉两种前景画笔，不需要单独标“血管”。模型输出为背景/静脉/动脉三通道；合并血管 mask 是两种前景的并集，概率为 `p(vein)+p(artery)`。管线中的 `CLASS_VESSEL=3` 仅代表旧仿体的类型未知标签，供部分标签 loss 使用，**不是第四个模型输出**。

PMC 论文 Fig. 4D 明确描绘一条颈动脉与一条颈内静脉；这不等于每帧全部动脉数量固定为一。原始 MAT 没有解剖标注，深部暗区不能仅凭外观认定为椎动脉，模型的红色预标注也不能作为身份依据。需核实的区域先跳过该帧，不按预设数量添加动脉。来源：[原论文 Fig. 4](https://pmc.ncbi.nlm.nih.gov/articles/PMC9883282/)。

同一数据集只运行一个标注服务，勿同时用桌面工具修改 CSV。Web 多窗口会检查帧版本；旧窗口保存会被拒绝，需重新载入，防止覆盖新结果。

## 标注完成后

### 黑图如何处理

| 实际内容 | 操作 | 原因 |
|---|---|---|
| 探头未接触、只有黑场/伪影，没有有效组织回声 | 排除训练，保留归档 | 不能作为正常组织背景或血管消失的真值 |
| 组织回声有效，静脉压扁、移出切面或暂时看不到 | 保留，按实际可见结构标注 | 模型需要学习真实消失与再出现；仍要检查动脉 |
| 只有画面边框黑，超声区域有组织 | 保留 | 黑色边框不代表无效采集 |
| 图像有效，但血管身份/边界拿不准 | 暂时跳过，结合前后帧复核 | 不应把不确定标签画成全背景，也不应当无效采集排除 |

无接触帧可以留作以后接触状态分类或独立鲁棒性测试，本轮从主分割与时序训练排除。不能仅凭「mask 为空」或整图平均亮度判定无效。2026-09-23 的初筛为 362 张中排除 44 张、保留 318 张，仍需人工复查；数字会随网页操作更新。

人工排除优先于自动筛选；恢复也能覆盖原来的自动无效判断。时序准备时，无效帧切断连续段，不能删除后把两侧帧拼成相邻帧。

本任务以目标颈动脉/颈内静脉为范围：每类最多一个连通区域，也允许没有。全空帧、仅动脉帧以及肉眼追踪到的受压细线静脉均可作为有效人工标签，不为凑齐两类补画血管。这个数量约定是当前任务范围，不代表所有颈部切面只有一条动脉/静脉。

```bash
python data/pipeline/dataPrepare.py --dataset pmc9883282 --validate-only
```

复查结束后，先重建训练缓存再启动新训练，旧缓存中的标签不会随网页自动更新：

```bash
python data/pipeline/dataPrepare.py --dataset pmc9883282 --no-png
python -m models.temporal.prepare --output /tmp/pmc_reviewed_temporal_cache
```

时序训练配置需指向这份新缓存。单帧训练与时序训练入口会检查标注快照，拒绝继续使用过期缓存。网页操作不会重训或覆盖现有 v11，也不会改写历史实验结果。

数据状态和训练流程见[研究与开发主文档](../../docs/ultrasound_world_model.html#next-steps)。Web 服务不会创建 checkpoint，也不会自动将预标注当成真值。
