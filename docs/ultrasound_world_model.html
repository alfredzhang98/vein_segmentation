01 · 研究主线与分阶段目标

目标： 把单帧“血管现在在哪里”升级为“根据历史，预测下一步血管往哪里移动、怎样变形、是否仍然可见”，再发展到“给定探头下一步动作和施力，预测其后果”。从可验证的血管状态起步，逐步加入空间运动、接触力和未来图像生成。

这份HTML是项目唯一维护的研究/开发主文档。模型细节、数据说明、当前进度与下一步入口统一在这里；通用训练/API说明仍留在各模块README。路线以本次最终约定为准，状态按实际工作更新，“定稿”不表示模型已经实现。

阶段 模型本质 新增输入 主要产物
S0 混合分割基线 普通单帧U-Net；“混合”指部分标签监督 五域单张图像 当前mask与可复用CNN encoder
S1 视觉world model CNN/U-Net encoder + Temporal Transformer + 当前/未来decoder 历史图像；无需IMU、无需force 未来mask、位置/方向、形状、可见性与不确定性
S2 运动条件world model S1 + 视觉—惯性状态与动作条件转移 可用IMU、相对起点位移/姿态、候选运动 空间运动估计、候选轨迹下的未来状态
S3 力—运动条件world model S2 + Force Encoder与形变响应 历史接触力；后续加入可执行施力命令 压缩/释放/塌缩趋势与耦合动作后果
S4 可选生成模型 共享预测状态 + future-image decoder 同上；可靠状态作为条件 未来B-mode、多种可能结果与导航演示

S1不是“纯Transformer替代U-Net”。CNN保留超声局部特征和空间细节，Transformer融合历史，预测头学习状态转移；world model不要求先生成像素图像。只改善当前帧分割的1A是预热，增加未来状态建模的1B才构成这里的视觉预测world model。S1可没有显式动作；S2/S3再发展为可控动作条件world model。

历史驱动的导航预测为本研究提供了启发。需要区分的是：NWM原论文预测未来观测时含导航动作。我们先做历史条件预测，再补动作条件；目前不宣称具有NWM式规划能力或真实人体3D导航能力。

相对于原提案“先物理仿真链”的顺序，本路线先利用已有真实数据获得预测基线。仿真在需要独立操控力/位姿、验证组织3D形变时加入，不阻塞S0/S1；完整物理解释仍需相应真值。

02 · 已有 CVC 系统与研究起点

本研究由 Qingyu Zhang（University College London）提出，延续已有的 CVC（中心静脉置管）辅助系统。前期工作题为 Bioimpedance-Informed Haptic Needle System with Human-in-the-Loop Control for Central Venous Access：超声定位血管，RGB 相机与 IMU 建立探头、针具之间的空间关系，针尖附近的 BioZ（生物阻抗）提供组织状态，触觉设备把这些信息转化为操作者可感知的引导。

前期稿件报告的 phantom user study 结果为 29/30 次成功进入血管（96.7%），最终定位误差 2.48 ± 1.55 mm，RMSE 2.92 mm。这些数字说明静态血管几何能够支持共享控制；它们属于已有系统的实验记录，并不是当前 world model 的预测或控制成绩。

读图1时，可以沿“感知 → 几何估计 → 对齐与引导 → 操作者反馈”理解这条闭环。已有超声模块用单帧 U-Net 得到血管区域，再通过形态处理和图像矩计算中心、深度、横向偏移与半径。它支持当下的定位，却没有建立“探头为什么改变了图像、下一步又会怎样”的动态模型。当前分割工程为保留受压静脉细线，后处理已采用更保守的规则，不能直接照搬早期形态学操作。

前期讨论提出接入探头力测量与序列建模。原因来自实际观察：静脉可能弱可见，压迫会改变表观直径，同一血管会随扫描截面变化在图像中移动。因此，本研究把当前几何估计向前延伸一小段时间，先预测位置、形状与可见性，再把这种预测接回探头引导。已有系统中的 RGB/IMU 能力，不代表当前五个分割数据集已经含有可直接训练的同步位姿；两者的数据接口仍需落实。

03 · 要预测什么，以及为什么会变化

研究的核心问题是：能否根据连续超声建立血管状态，并在加入可靠的运动、接触力和候选动作后，区分扫描截面变化与组织受压形变，提前预测操作后果？ 图2把这两种机制分开，说明为什么仅看一张 mask 不足以解释变化。

可检验的假设是：连续历史比单帧更有利于预测；加入可靠运动与力后，模型对相应变化的预测进一步改善；经过标定的物理形变监督，有望提高对未见动作组合的泛化。这里的“区分”是待验证的能力，而非网络中设置两个 token 就能保证的结果。

由此形成三个相互衔接的研究目标：建立可追溯的真实／合成多模态数据；学习未来血管状态；用候选动作 rollout 支持兼顾定位、可见性和压迫程度的探头决策。先完成前两项的低模态版本，再推进完整交互模型。

3.1 三种不同的问题

问题 推理时可用信息 应输出什么 可以验证的能力
当前感知：现在血管在哪里？ 截至当前的历史图像，可选历史 pose/force 当前 A/V mask、位置、形状、可见性 时序是否改善分割、细线识别和稳定性
历史预测：按目前趋势继续，接下来可能怎样？ 仅截至当前的观测；未来动作未知 未来 mask、位置分布、移动方向、形变趋势、消失／重现概率 是否比复制上一帧、恒速外推更准
动作条件预测：如果下一步这样移动／施力，会怎样？ 历史观测 + 推理前已知的候选动作序列 每个候选动作下的未来状态与不确定性 是否能预测动作差异，而非只延续历史趋势

例如：人看到静脉连续变扁，可以推测下一帧可能继续收缩；但若操作者突然抬起探头，历史本身不能唯一决定结果。因此先学历史条件的未来分布，再引入已知动作条件。预测应表达“可能的位置与形变”，不能把未知的下一步操作当作已知。

3.2 状态、预测时域和动作

记历史为 H_t = {I_i, 可用的 P_i, 可用的 F_i, 时间/顺序及模态有效标记}_{i=t-K+1…t}。阶段1完全屏蔽 force 输入，阶段3才启用。P_i 只表示实测或经过验证的位姿；图像学习的运动特征另记为 z_motion。

z_t = Encoder(H_t)
当前状态 S_t = CurrentDecoder(z_t)

历史预测：       p(S_(t+1:t+H) | H_t)
动作条件预测：   p(S_(t+1:t+H) | H_t, a_(t:t+H-1))

第一轮从一个未来采样点开始，再扩展到多步。没有可靠时间戳时，t+1 指该来源的下一个已记录采样点，不声称是下一原始视频帧或固定毫秒。Mus-V 已经过下采样，不能从导出序号推断原视频帧率；PMC 预览视频的20 fps也不能用于训练时间标定。

模型的主要输出定义如下：

输出 首先采用的表示 缺失／退化情况
当前与未来 A/V mask 背景、静脉、动脉三通道概率 可以只有一种，也可以全背景
血管位置 每类中心热图、中心分布；可见时提取质心 不可见时中心无效，不回归到 (0,0)
移动方向与距离 图像平面 Δx, Δy，由位置预测和运动头交叉验证 无时间戳只报像素／采样步；位移近零不计算方向角
形状与压缩趋势 面积、轮廓、主／短轴、面积变化率 细线保留；接近圆形时主轴方向不稳定，应屏蔽该指标
局部表观运动 2D flow／warp 与轮廓变化 是图像对应关系，不自动等于组织3D形变
可见性与不确定性 每类可见概率、位置／轮廓置信区间 消失时停止实线 mask；保留内部轨迹可用单独虚线提示
后续物理输出 患者参考系下的位置、运动、组织形变场 仅在有空间标定、位姿和相应真值时启用

血管合并结果始终为 V = vein ∪ artery，不增加第四个模型类别。颜色为蓝静脉、红动脉；独立预测层重叠时显示绿色，合并血管视图整体绿色。当前 softmax argmax 输出互斥。真实观测与未来预测应分屏／虚线显示，不能混成已观测到的血管。

4.1 在写时序模型前解决的数据约束

  1. Mus-V：按文件序号和力文件行号关联，确认行数、顺序、单位、符号和传感器坐标。作者代码使用第3列并以较负值对应较强压迫；接入时保留原始量，记录归一化和符号约定。本地 datasets_info.xlsx 只提供视频、帧数和split，不能当患者映射表。
  2. PMC：围绕有标签的原始帧读取真正相邻的MAT上下文。预测有标签帧 j 时，输入只能到 j-h，不能把 I_j 混入输入。其余未来无标签帧不填空mask，也不当作有监督真值。
  3. Mendeley：优先恢复DICOM采集组与患者对应，确认slice是否时间维及间隔。在此之前只用单帧标签；可研究带明确采样间隔的序列，不能把两个相距很远的slice当下一帧。
  4. 自采仿体：时间相近不等于连续视频；先依据采集session、时间间断、深度／设备设置切段。只在找到连续原始记录后开时序监督，否则保留为单帧域。
  5. 标签完备性与可见性分开：mask_available=False 表示未标，不表示无血管。full3空mask才可监督两类不可见；Mendeley不允许监督静脉可见性负样本；仿体只监督合并血管可见性。

4.2 划分与泄漏控制

  • 所有窗口先依据固定split取样，同一原始帧不能跨训练/验证/测试；验证/测试的未来图像也不得用于训练自监督。
  • Mus-V现实现为官方train 80段/2203帧，官方valid 25段/911帧再按序列分为val/test。此为序列隔离，尚不能声称患者隔离。恢复受试者映射后，新增按患者留出的实验；保留旧split仅作历史可比结果。
  • PMC保持subject20/train 120个标签、subject2/val 30、subject21/test 30，同一人的其他未标帧归同一split。三人规模仅支持先导验证，不能外推为广泛临床泛化。
  • Mendeley现有随机帧划分可能把同一采集组分到两边；时序实验至少按采集组隔离，患者映射确认后按患者隔离。旧单帧指标不能直接宣传为独立患者泛化。
  • 两个仿体按session/扫查/对象分组；保留已指定test记录。单一仿体的测试说明的是该对象上的条件变化，不等于新人体泛化。
  • 所有归一化、阈值、标注补采和模型选择规则只用训练/验证决定。置信区间以患者或序列为单位，不能将大量重叠窗口当独立样本。

09 · S2 · IMU、相对运动与动作条件

9.1 A. 从视觉运动latent走向视觉—惯性状态估计

阶段1已经是以预测为目标的观测驱动视觉world model；其中1A仅为当前分割预热，1B才训练未来状态转移。阶段2是在同一个状态模型中加入运动观测，不重新做一套互不相关的网络。

先保持双路径：图像路径继续使用所有有序序列，学习2D移动与外观变化；视觉—惯性路径在有同步IMU的序列上融合角速度、加速度和相对姿态。缺IMU的已有五域仍通过模态有效标记参与相应任务。模型从训练中就要经历模态dropout，评估无IMU回退能力。

IMU本身不是位置传感器。加速度包含重力、零偏与噪声；两次积分会累积漂移；单个起始点只能定义原点，不能消除后续漂移。6轴IMU的偏航也可能漂移。参考MoNet可研究图像与惯性融合，但不能把运动latent或未经校准的积分量叫作精确6DoF真值。

9.2 B. 起点参考系与数据接口

固定起始探头参考 P₀，约定 T_WP(t) 将探头坐标映射到世界/跟踪坐标，则：

T_P0_Pt = inverse(T_WP(0)) × T_WP(t)
ΔT_t    = inverse(T_WP(t)) × T_WP(t+1)
T_WU(t) = T_WP(t) × T_PU

T_PU 是超声平面到探头的外参；像素到平面还需spacing与裁剪/缩放记录。希望输出人体坐标时，需要患者参考、体动跟踪或明确的短时间患者静止假设。探头相对起点轨迹并不自动等于血管在人体内的组织点轨迹，截面中心也不一定是同一个3D组织点。

IMU接口至少保存硬件时间戳、ax,ay,az,gx,gy,gz、单位、坐标轴方向、采样率、零偏/重力处理、探头—IMU外参、同步延迟与置信度。IMU通常高于图像采样率，应在图像区间内做带时间的聚合/预积分，而不是按行号任意对齐。位移来源、协方差和重定位/原点重置事件也要记录。

9.3 C. 运动条件world model与NWM式候选轨迹

状态编码器融合历史图像、可用IMU及相对轨迹，Dynamics接受候选未来平移/旋转。输出每条轨迹下的未来血管位置、形状、可见性和不确定性。可增加目标条件，如“使目标血管回到视野中心”，用rollout评估候选轨迹；初期只作离线排序，不直接让模型控制探头。

两种模式必须单独评估：history-only 根据历史隐含动作分布外推；motion-conditioned 给定真实可用的候选动作预测。训练中未来实测pose可作为响应真值，或明确标识的理想条件上限，但不能冒充操作前就知道的未来实测输入。需要记录命令与实测执行结果，评估实际执行偏差。

参考Navigation World Models，借鉴的是“状态—动作—未来观测/状态—轨迹评估”这条链。NWM本身包含动作条件，不能把它简化成无动作视频外推。这里不照搬其大规模自然视频模型：超声先预测可检查的mask和几何，图像生成后置。

训练目标： 延续当前/未来混合分割与可见性损失；仅有可靠运动参考的样本增加相对平移/旋转误差、轨迹一致性与重投影/配准约束。SO(3)旋转误差与平移分开度量，避免直接对Euler角无约束回归。位姿误差报告ATE/RPE或相应短窗误差，分开有无尺度/对齐条件，不用评估对齐掩盖真实部署漂移。

验收： 在独立序列中，相比仅图像模型，IMU/相对位移应改善预测或定位；打乱IMU/动作后性能应下降；选择相反候选移动时预测应产生合理方向差异；长窗口需报告累计漂移与不确定性。未拿到同步运动数据时，阶段1可独立交付；随后也可先开展阶段3的已有力历史可行性实验，不宣称完成本阶段。

10 · S3 · 接触力与血管形变

10.1 S3A——先使用已有真实力历史，不等待仿真

在阶段1/2共享模型上增加Force Encoder／force token，与图像、可用pose一起输入Transformer。先在Mus-V做单一来源实验，保持其余结构和数据划分不变，验证力是否真的带来增益；再在完成同步验证的PMC上做外部验证或联合训练。

力的表示与同步：

  • Mus-V：保留六维wrench原值。第一轮先选经方向约定的法向力代理与变化量，之后再比较全部力/力矩；法向投影必须有传感器到探头的旋转关系，没有时明确标为轴向代理。
  • PMC：force/time属于力采样时间，不能直接按帧数均匀拉伸配对。结合采集说明、可观察同步事件、延迟估计和人工检查形成同步误差范围；达不到要求就继续只用图像，不将其强行用于细粒度力—形变监督。
  • 使用训练集归一化统计，记录单位、零偏、重力补偿和符号；不同设备原始轴值不能直接混用。力N不是压力Pa，缺少接触面积时不能称为压力。
  • 时间未知时输入 ΔF/采样步，不称为牛顿/秒。采用力历史而不只用单个 F_t，才能观察加载／卸载差异和滞后。
  • 不含力的其他域继续做分割或图像时序任务；用force-valid标记、缺失token及模态dropout保持无力推理能力，不用0N伪装缺失。

增加的预测包括面积／短轴变化、轮廓收缩／展开、可见性和图像表观形变。保留独立动静脉输出，不假设动脉绝对不变。此步仅根据历史实测力预测自然后续，仍不是“指定下一步施力”的反事实模型。

如何判断数据够不够： 105段配对Mus-V序列足够启动可行性实验，但不保证泛化。按序列/受试者、加载/卸载、力幅度和塌缩事件画学习曲线，比较无力模型、正确力、打乱/错位力及缺失力。如果正确力没有稳定收益，先检查同步、坐标与条件覆盖，不能用网络规模替代证据。

此时图3的 force 与 action 分支全部启用：历史图像、位姿和力形成状态，候选动作进入转移模块，再输出未来 A/V mask、几何、形变与不确定性。动作条件的验证方法见候选操作与控制。

动作必须对应真实控制接口。例如切向平移/旋转加法向力设定值，或位姿增量加压入命令。不能把法向位移和法向力都当作可任意、独立精确实现的命令；混合控制的自由度与执行器响应要写清楚。模型可先预测实际pose/force响应，再预测血管状态。

若机器人日志或仿体实测仍不能提供3D形变真值，再使用经过真实力—截面曲线校准的简化力学仿真：组织块、血管、探头接触起步，保存位姿、接触力、网格位移/形变、截面mask及可选B-mode。仿真作用是提供可控干预和隐藏物理状态，不要求一开始完成整个人体或实时渲染。

形变监督分级：

  1. 仅有mask：监督截面积、轮廓和轴长变化；这是可观测的截面变化。
  2. 有配准／可靠对应：增加2D表观形变，记录对应置信度。
  3. 有3D网格/组织点真值：才监督物理位移场 u(X,t)、应变或材料响应。

图像flow、两个mask相减、6维latent均不能自动当作第3级真值。模型里设置“motion token”和“deformation token”也不保证真的解耦，需要受控实验支持。

完成标准： 在隔离的动作组合/对象上，给定候选动作的模型优于历史外推和无动作消融；定量报告位置、形变与可见性误差；变化候选运动和候选力时，分别能预测对应的结果及不确定性。若数据仍有强相关混杂，只报告条件预测收益，不宣称完整因果辨识。

11.1 先跑通一个可标定的力学单元

最小场景由软组织块、内嵌可压缩血管和刚性线阵探头组成；需要比较 A/V 响应时加入不同材料或结构的动脉与静脉。逐步改变压入深度，记录接触力、节点位移、变形网格及血管截面。准静态示意关系为 u_t(X) = FEM(a_t, material, boundary conditions)；若研究动态或滞后，还必须输入前一状态、速度、时间步长与加载历史，不能让同一瞬时力唯一决定全部形变。

SOFA 可作为生物力学建模与约束表达的候选方案，已有探头—组织交互教程。PhysX deformables 是与机器人仿真整合的另一候选；是否适合本项目的静脉塌缩，必须通过加载／卸载、接触稳定性及真实截面趋势评估后决定。先选择能稳定复现最小实验的方案，不把选用某个软件作为研究贡献。

图5曾在早期提案中标为“已运行的 FEM 测试”。当前工作区尚未验收对应代码、材料参数和数据导出接口，因此这里区分已有截图与可复现训练链。下一步需要从每个求解状态导出节点 ID 与位移、接触力和带标签网格，并验证卸载后回程、网格稳定性、坐标与单位；不能只根据表面颜色判断模型已具有可信物理监督。

11.3 接口、同步和最小可行实验

力学顶点、表面网格、声学材料 ID 与血管标签应有可追溯映射；记录探头到图像平面的外参、毫米／米转换、时间步与声学设置。每个力学状态完成后，用同一网格和探头位姿导出 B-mode 与 mask，再保存几何量（中心、面积、长短轴等）。先离线逐状态渲染，动态 mesh 实时更新不是训练前提。服务器无法安装模拟器时，在具备依赖的环境离线生成兼容数据，当前学校服务器仍可开展 S0/S1。

物理 MVP：设置少量加载／卸载档位 → 得到稳定的 force–area/deformation 曲线 → 导出对应 B-mode 与 mask → 训练短序列模型预测下一步 mask/area。在固定截面、固定生理条件的该实验中检查“力增加、静脉面积减小、超声形状同步改变”，再验证已知动作下的预测。这个趋势是实验约束，不是对所有人体视频逐帧强加的规律。

已有真实 force–US 数据承担校准与外部验证；后续大规模材料和动作组合可由仿真补充，避免把项目建立在新的大规模真人采集上。不过，没有实际动作／位姿记录时，仿真收益仍需通过受控仿体或可用机器人日志验证，不能单靠合成结果声称人体控制泛化。

14 · 候选操作预测与共享控制

状态预测通过验收后，S2/S3 可以开始离线比较候选动作。控制与图像生成是两条扩展：只要未来 mask、几何和可见性足够可靠，就能研究动作排序，无需先生成逼真的 B-mode。 接入真实执行则还需要独立的动作覆盖、响应误差和闭环验证。

图6用同一当前状态展开三条路径。各分支必须从同一历史开始，只改变候选操作，才能比较模型是否学习了动作差异。示例中的“压入 1 mm”“平移 2 mm”只是解释动作表示，不是人体操作建议或已验证的控制参数；真实候选集合由设备能力、实验标定和数据覆盖决定。

14.1 控制目标与共享控制接口

a*_t = arg min_a [ L_target + λF L_force + λD L_deformation + λU L_uncertainty ]

L_target：目标位置偏差，并包含可见性不足的代价
L_force：接触力偏离标定范围或约束的代价
L_deformation：过度压缩 / 塌缩及不利几何变化的代价
L_uncertainty：对超出训练覆盖或高不确定性动作的惩罚

该目标保留早期提案的动作选择形式。多步版本对预测时域累计代价，并施加设备可实现的位姿、速度和力约束；权重与阈值来自验证实验。若全部候选都不可靠，应回到已验证的保持／人工控制策略，而非从不可靠候选中强选一个。

CVC 场景中的具体目标是让目标静脉处于可操作位置并保持足够可见，同时限制过度压迫。与图1的衔接点是 guidance：旧系统根据当前几何给出对齐和触觉引导；新模型可用未来的定位、塌缩风险和不确定性更新引导。BioZ 与针具反馈仍由原系统承担，不能用超声预测冒充针尖组织状态测量。

14.2 按证据逐级开放

  1. 离线：对数据覆盖的已记录动作预测后果；对未执行动作只能给出假设，不能宣称反事实已验证。
  2. 仿真闭环：从可重复初始状态执行不同动作，比较位置、可见性、压缩、力约束与任务成功率；对比仅依据当前几何的控制和无模型策略。
  3. 仿体共享控制：完成同步、响应和回退机制验证后，让模型先提供建议，再评估有限动作执行；单步看起来准确不等于多步控制稳定。

若项目时间不足，交付离线动作排序与仿真闭环即可，把真实机器人控制明确列为后续扩展。完整 future B-mode 不是上述控制实验的必要条件。

15 · S4 · 未来超声图像生成

先保证mask/几何预测可靠，再增加状态条件的图像decoder，生成未来B-mode或多个可能的未来片段。可采用轻量重建头起步，数据量支持后再考虑更重的生成模型；不将视觉真实感代替位置/形变准确率。

生成头应以同一预测状态和动作条件为输入，与未来mask保持几何一致。真实超声散斑和离面变化可能具有多解，因此既看重建指标，也看生成图像中的血管位置是否与预测mask一致、是否虚构持续可见的血管。训练/验证不得把生成图当人工标签。

第一版用户演示包含：历史帧、当前真实图、未来预测轮廓/位置分布、预测时域与置信度；到达未来时刻后再叠加真实图进行核对。动作条件阶段可并排显示“保持”“平移”“减小接触力”等数据覆盖范围内的候选rollout。该功能先做离线预测验证，不直接接自动执行。

16 · 研究贡献与论文定位

完整目标是一个 physics-grounded force- and motion-conditioned ultrasound world model：联合连续 B-mode、探头位姿、接触力与候选动作，学习探头交互、血管形变和超声观测的动态关系；在具备可信物理监督时约束潜在状态，并为形变感知的机器人超声提供前瞻性估计。

U-Net / CNN perception
  + 可用 Force / Pose tokens
  + Temporal Transformer state and dynamics
  + 当前 / 未来状态解码
  = Ultrasound World Model

这一最终定义不要求 S1 就拥有全部模态。S1 首先验证视觉未来状态；S2/S3 增加可验证条件；只有完成力学标定与形变监督实验，才在论文中使用 physics-grounded 描述实证贡献。

拟贡献需要的证据当前边界
Interaction-aware formulation运动、力及动作条件对相应预测的独立作用不能把相关趋势当成完整因果辨识
Physics-grounded synthetic supervisionFEM 与 B-mode 同步；物理真值、校准和消融工具组合或漂亮形变动画本身不是创新
Predictive vascular state modelling未来 mask / geometry / deformation 优于合理外推改善当前分割不等于未来预测
Decision use of the modelrollout 改善动作排序或闭环效果；真实趋势验证离线图像生成不等于机器人控制完成

论文应围绕这些机制组织，而非罗列 U-Net、LSTM、Transformer、Diffusion、Flow Matching 的大规模模型排名。已有力引导时序分割工作，因此“首次加入 force token”或“首次用 Transformer 分割血管”不是可直接采用的贡献表述。

面向完整阶段的推荐标题为 Physics-Grounded Force–Motion World Model for Deformation-Aware Robotic Ultrasound；若强调血管应用，可用 Force-Conditioned Deformable Vascular World Model for Robotic Ultrasound。若只完成视觉阶段，标题应相应收敛到历史条件血管状态预测。

预期完整交付包括：同步 force–pose–deformation–ultrasound 序列管线；可复现的未来血管状态模型；形变感知的候选动作评价方法；已有真实 force–US 数据上的校准、域差距与泛化验证。各项分别验收，不能以其中一项完成代替整个系统完成。

17 · 风险与降级路径

现有真实数据允许先验证视觉预测，但完整研究仍可能受同步、物理可信度与动态网格接口限制。降级时缩小可证明的结论，保留已经成立的数据与模型能力。

风险影响可执行的降级路径
缺少可靠 IMU / pose 或积分漂移无法验证真实 6-DoF 导航保留 S1 图像坐标预测；S2 先做同步和短程误差验证，不把 latent 命名为真实位移
PMC 力／图像同步不明确细粒度力—形变对应失真继续使用其图像与标签；先用 Mus-V 做力历史可行性实验
动态 deformable mesh 无法高效送入超声模拟器实时 FEM → US 链路受阻离线逐状态导出与渲染；训练不依赖仿真实时运行
PhysX 静脉塌缩不准确或网格不稳定形变监督可信度不足用 SOFA 或真实趋势作参考；缩小到可标定的面积／椭圆截面响应，不把简化结果当完整组织物理
合成 B-mode 与真实域差距大迁移后分割与预测下降真实 force–US 校准、声学／材料随机化；优先 mask 和 geometry，推迟像素生成
完整多模态模型训练不稳定难定位误差来源先当前／未来 mask，再几何与可见性；仅有对应真值时加 deformation，最后加图像头
控制阶段资源或时间不足缺少完整机器人闭环先验收动作预测及仿真闭环，保留真实共享控制为后续工作
空帧与受压细线容易误判虚构血管或抹掉真实细结构按可见性分层评估，保留空mask与细线，不用时序平滑或面积过滤掩盖错误

这些降级路径不改变主顺序：先得到可复现的五域分割基线，再验证真实序列中的未来状态。只有当一个新增模态或物理支线回答了明确问题，才增加相应模型复杂度。
